# Galmuri (한글 도트 글꼴)

- 출처: https://github.com/quiple/galmuri (npm `galmuri@2.40.1`)
- 라이선스: SIL Open Font License 1.1 — 전문은 `LICENSE.txt`
- 사용 파일: `Galmuri11-Condensed.woff2`(본문), `Galmuri11-Bold.woff2`(제목·버튼)
- 이 두 파일만 쓰는 이유: 공식 README "Legal Stuff" 에 따르면 Galmuri14·11·9(일반) 는 한글 음절 2,355자 등이 저자의 순수 창작이 아니고,
  **Galmuri11 Bold 와 Galmuri11 Condensed 는 모든 글리프가 저자의 순수 창작물**이다. 배포 서비스에서는 출처가 명확한 쪽을 쓴다.
- 외부 CDN 없이 `public/fonts/galmuri/` 에서 직접 제공한다(`src/styles/pixel-theme.css` 의 @font-face).
