# 방명록 관리자 삭제 설정

관리자 삭제 기능은 기존 `jeju_guestbook` 테이블과 RLS 정책을 변경하지 않습니다. 브라우저에는 Supabase 관리자 키를 전달하지 않고, 서버 함수가 관리자 비밀번호를 확인한 뒤 선택한 글 하나만 삭제합니다.

## Vercel 환경변수

Vercel 프로젝트의 **Settings → Environment Variables**에서 다음 값을 Production에 추가합니다. Preview에서도 시험하려면 Preview에도 따로 추가합니다.

- `GUESTBOOK_ADMIN_PASSWORD`: 16자 이상으로 만든 관리자 전용의 강한 비밀번호
- `SUPABASE_SERVICE_ROLE_KEY`: 이 앱의 Supabase 프로젝트 서버 전용 Secret key

두 값 모두 Secret으로 등록하고 `VITE_` 접두사를 붙이지 마세요. 키는 브라우저 번들에 포함되면 안 됩니다. 환경변수를 저장한 뒤 새 배포를 만들어야 적용됩니다.

## 사용 방법

상단바 맨 오른쪽의 자물쇠 아이콘을 누르면 방명록으로 이동하며 관리자 비밀번호 입력창이 열립니다. 비밀번호를 확인하면 글마다 **이 글 삭제** 버튼이 나타나고, 삭제 전 확인창이 표시됩니다. 관리자 모드는 현재 페이지에만 유지되며 새로고침하면 종료됩니다.

로컬 개발에서는 프로젝트 `.env.local`에 두 변수를 설정하고 Vite 서버를 재시작합니다. 실제 비밀번호나 키를 저장소에 커밋하거나 메시지·로그에 붙여 넣지 마세요.

환경변수가 없거나 관리자 비밀번호가 16자보다 짧으면 서버는 삭제 요청을 거부합니다. 삭제 시 Supabase Secret key 권한을 사용하므로 해당 키는 신뢰할 수 있는 서버 환경에만 보관해야 합니다.
