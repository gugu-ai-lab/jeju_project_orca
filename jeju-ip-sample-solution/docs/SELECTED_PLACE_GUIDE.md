# 장소 선택 → 실제 위치·예보·길찾기 자동 연결

## 구현 범위

통합 브랜치 `codex/integration-student-app`에서만 구현했다. AI 안내원은 별도 화면으로 유지하며 OpenAI 호출 없이 동작한다.

SVG 핀을 선택하면 오른쪽 카드의 장소명·주소·좌표·관련 신화와 함께 실제 카카오맵 중심·마커, 해당 지역 단기예보, 카카오맵 목적지 링크가 갱신된다. 출발지는 지정하지 않고 GPS도 요청하지 않는다.

자청비는 농경 신화의 인물이다. 자청비 자체를 장소나 날씨로 취급하지 않는다. 현재 검증된 단일 관광 장소가 없으므로 이야기만 표시하고 임의의 지도 좌표·예보·길찾기는 제공하지 않는다.

## 현재 카카오 실제 지도 제한 — 설정 필요

현재 카카오 SDK 요청 결과:

- `http://127.0.0.1:5181`: HTTP 401, `AccessDeniedError`, 도메인 관련 오류.
- `http://localhost:5181`: HTTP 401.
- 같은 키와 `http://localhost:5173`: HTTP 200 JavaScript.

따라서 키를 새로 발급할 문제가 아니라 통합 미리보기 주소 허용 설정이 필요하다. 실제 카카오 지도가 성공적으로 표시됐다고 보고하지 않는다. 코드의 지도 중심·마커 연결과 장소 전환·복귀는 모의 SDK로 확인했다. 공식 SDK의 실패 상태도 실제 브라우저에서 확인했다.

카카오 개발자 사이트에서 해당 앱 → 앱 설정 → 앱 → 플랫폼 키 → 사용 중인 JavaScript 키 → JavaScript SDK 도메인에 `http://127.0.0.1:5181`을 추가한다. localhost로 접속하려면 `http://localhost:5181`도 추가한다. 기존 도메인은 삭제하지 않는다. 저장 후 미리보기 페이지를 새로고침한다. 앱 설정은 이번 작업에서 변경하지 않았다.

[카카오 공식 지도 가이드](https://apis.map.kakao.com/web/guide/)의 준비하기와 길찾기 바로가기 형식을 사용했다. 길찾기는 `/link/to/이름,위도,경도`이며 선택한 장소만 목적지로 전달한다.

## 장소 데이터 재검증

기존 JSON의 둥근 좌표와 복합 장소명을 그대로 날씨에 사용하지 않고 공식 API로 확인했다.

| 신화 | 선택한 실제 장소 | 근거 |
| --- | --- | --- |
| 설문대할망 | 제주돌문화공원 | TourAPI 문화시설 ID 1544730 |
| 삼성혈 | 제주 삼성혈 | TourAPI ID 127744 |
| 혼인지 이야기 | 혼인지 | TourAPI ID 126465 |
| 수월봉과 녹고물 | 수월봉 | TourAPI ID 126434 |
| 산방덕이 | 산방굴사(제주) | TourAPI ID 126457 |
| 영등할망 | 건입동 칠머리당 | 제주역사문화위치정보 ID 1635 |

돌문화공원 좌표를 한라산 영실의 좌표로 설명하지 않는다. 칠머리당과 영등굿 전수관도 서로 혼동하지 않는다. 위치 API로 확인된 칠머리당의 주소·좌표를 사용했다. 혼인지·산방굴사의 기존 주소와 좌표도 공식 응답으로 정정했다. 신화 본문과 퀴즈 내용은 수정하지 않았다.

## 기상청 조회

- 기존 기상청 `getVilageFcst` 재사용. 도시명 조회의 기존 배열 응답과 AI 도구는 유지.
- 새 경로: `/api/weather?mythId=seolmundae` 등. 서버가 검증된 JSON 좌표를 찾아 격자로 계산하므로 브라우저가 임의 격자를 지정하지 않는다.
- LCC 투영은 [기상청 동네예보 격자 정보](https://apihub.kma.go.kr/getAttachFile.do?fileName=%2820240305%29%EB%8F%99%EB%84%A4%EC%98%88%EB%B3%B4+%EA%B2%A9%EC%9E%90%EC%98%81%EC%97%AD+%EC%A0%95%EB%B3%B4.pdf)의 5km 간격·기준점·지구반경을 사용.
- 일 8회 발표(02/05/08/11/14/17/20/23시) 중 현재 한국 시각에서 15분 여유를 둔 회차 선택. 자정의 날짜 변경 처리.
- 현재 시간대 이후 예보 6건 중 카드에는 앞 3건을 표시. 발표 시각과 각 예보 대상 시각을 한국 시각으로 구분하고 ‘현재 관측값이 아닌 주변 지역의 예보’라고 표시.
- 성공 결과는 장소별 3분 캐시. 시간대 또는 발표 회차가 바뀌면 캐시를 다시 조회.
- 장소 전환 시 이전 요청 취소. 늦은 응답을 새 장소 카드에 표시하지 않는다.
- 날씨나 지도 실패 시 짧은 안내를 표시하고 SVG·이야기·퍼즐·길찾기는 유지.

## 테스트 및 보존

- 전체 자동 테스트 55개: 기존 기능과 격자·발표 회차·날짜 경계·위치 없는 신화 차단·캐시 갱신 포함.
- 새 브라우저 검증 5항목: 두 장소 실제 예보/모의 지도, 자청비 차단과 장소 복귀, 늦은 응답 무시, 지도·예보 실패 중 퀴즈 완성. GPS 요청 0회 감시.
- 기존 통합 브라우저 8항목 재통과: 지도 선택, 이야기, 퍼즐, 모의 AI 표시·즐겨찾기, 실제 사진.
- 재검증 도중 국가유산 사진 2건이 일시적으로 누락되어 기존 사진 검증이 한 번 실패했다. 해당 서버 코드는 변경하지 않았고 재조회한 회귀 실행에서는 기존 7건 모두 로딩됐다. 이를 사진 원본 부재나 이번 기능의 지도 오류로 처리하지 않았다.
- 빌드 성공, 린트 오류 없음. 기존 관광/국가유산 효과 관련 경고 4개 유지.
- OpenAI 유료 요청 0회, Supabase 요청·SQL·배포 없음. 원본 Codex와 Gemini 브랜치·기존 개발 서버 유지.
- 미리보기: `http://127.0.0.1:5181/`. 날씨용 새 환경변수는 없고 기존 `DATA_GO_KR_KEY`를 재사용. 지도는 기존 `VITE_KAKAO_MAP_KEY` 사용.
