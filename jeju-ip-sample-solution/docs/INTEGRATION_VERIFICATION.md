## 충돌 해결 기준

- Gemini 보존: Home, SVG 2.5D 지도, JSON 핀 데이터, 신화 데이터·이미지, 이야기 탐색·상세, 퍼즐 컴포넌트·문제, CSS, Bootstrap 기반 디자인, 레이아웃, 라우터. Home에는 이야기 저장 버튼만 추가했다. StoryDetail도 저장 버튼만 추가했다.
- Three.js 미니어처 파일과 기존 의존성 보존. 최신 Gemini 의도대로 3D 탭을 다시 켜지 않았다.
- Codex 보존: `api/`, `server/`, Supabase `services/`, 자동 테스트, 국가유산 사진 7건·출처·오류 대체, Vite `localApi()`, OpenAI 비용 제한·오류 처리·한국 시각·빈 결과 안내.
- 공통 client는 Codex 오류 처리와 도구 직접 조회 함수를 유지했다. Store는 Codex 대화 제한을 보존하면서 즐겨찾기 부분만 새 서비스로 교체했다.
- `package.json`과 잠금 파일은 필요한 프론트 의존성을 이미 포함한 Codex 버전을 유지했다. 이전 Anthropic 런타임을 다시 도입하지 않았다.
- README와 환경변수 예시는 통합 내용·지도 키·안전 미리보기 설정을 추가했다. 실제 키 값은 파일·커밋·출력에 포함하지 않았다.

## 즐겨찾기 범위

이야기는 기존 고유 ID로 저장한다. 기존 관광·유산 카드의 즐겨찾기 버튼은 `tour:<id>`, `heritage:<name>`으로 구분하여 기존 장소 저장 기능도 유지한다. 서비스에는 `storyId`, `storyTitle`만 전달하고 소유자는 익명 인증으로 결정한다. 기존 RLS·스키마·권한은 변경하지 않았다.

이야기 목록에 존재하는 기록에만 상세 링크를 표시한다. 장소 기록이나 홈에만 있는 이야기의 미존재 상세 경로를 만들지 않는다. 닉네임은 데이터 소유권으로 사용하지 않는다.

## 퍼즐

Gemini의 3문제·3조각, 순서와 무관한 정답 처리, 중복 조각 방지, 오답 시 기존 조각 유지, 완성 그림·축하 애니메이션을 유지했다. DB 저장은 추가하지 않았다. 새로고침하면 퍼즐은 기존처럼 초기화된다.

`PUZZLE_SUPABASE_SPEC.md`는 참고 제안이며 실행한 SQL이 아니다. 향후 저장을 추진하면 인증 사용자 ID와 RLS 기준으로 별도 설계·승인이 필요하다.

## 미리보기와 환경설정

- 주소: `http://127.0.0.1:5181/`
- 기존 5173~5180 포트는 종료하거나 변경하지 않았다.
- 통합 `.env.local`은 Git 무시 대상이고 원본 설정을 덮어쓰지 않았다.
- 설정 이름: `DATA_GO_KR_KEY`, `OPENAI_MODEL`, `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, `VITE_KAKAO_MAP_KEY`, `VITE_INTEGRATION_READ_ONLY`.
- 안전 설정: `OPENAI_API_KEY`는 빈 값, `VITE_INTEGRATION_READ_ONLY=true`. 실제 서비스 검증은 별도 승인 후에만 키 설정·안전 모드 해제를 검토한다. 브라우저 번들에 OpenAI 키를 넣지 않는다.
- `ANTHROPIC_API_KEY`는 비어 있고 필요하지 않다.
