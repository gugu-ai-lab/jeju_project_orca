# 국가유산·관광 사진 추가 점검

## 집계 범위

2026-11-02 현재 빈 검색어로 표시되는 국가유산 첫 페이지 10건을 전수 확인했다. API 전체 검색 대상 479건의 사진을 모두 조사한 것은 아니다. 전체 479건과 화면의 10건을 혼동하지 않는다. 원본 사진이 있는 항목 10건, 없는 항목 0건, 연결 성공은 기존 2건에서 7건으로 증가했다.

사진별 식별번호·실제 URL·이용허락 코드·공식 원문은 `HERITAGE_IMAGE_INVENTORY.json`에 기록했다. 파일명과 사진 ID가 다른 사례도 확인하여 공식 사진 원문 ID를 별도로 보존했다. 예: 제주향교 파일 `2016061316550500.JPG`, 사진 ID `3487850`.

## 원인 분류

- 국가유산 목록 API: 이미지 필드 없음. 별도 이미지 API에는 기본 10건 모두 사진 있음.
- 기존 연결 누락: 승인 목록을 2건으로 제한했던 것이 원인. 공식 사진 원문에서 1유형을 확인한 5건 추가.
- 사용 조건: 나머지 3건은 이미지 없음이 아니라 이번에 승인한 1유형 사진 없음. 사진 사용 불가가 영구 확정된 것은 아니며 다른 유형 조건을 검토한 후 별도 판단 가능.
- 이미지 URL 오류: 연결한 7건은 최종 실제 Chrome 사진 로딩 성공. 공식 URL의 HTTPS 사용.
- 브라우저 차단: 정상 검증에서 차단 없음. 강제 네트워크 차단 테스트에서는 해당 사진만 기본 그림으로 바뀜.
- 일시적 제공기관 응답 실패: 첫 브라우저 점검에서 기존 두 사진의 메타데이터가 빠진 응답을 관찰했다. 코드가 오류를 숨기고 목록·기본 그림을 유지했으며 재조회 후 7건 모두 정상 복구됐다. 조회 실패를 사진 원본 부재로 집계하지 않았다.
- 관광·문화 화면은 원래 `firstimage`를 카드에 전달하고 있었으므로 한수풀의 원인은 프론트엔드 누락이 아님.

## TourAPI 비교

한국관광공사 KorService2 검색 결과에서 다음을 확인했다.

- 관덕정(제주), ID `126460`, 관덕로 19: 사진 있고 `cpyrhtDivCd: Type1`. 국가유산의 관덕정 주소와 일치하는 대체 후보지만 기존 공식 유산 사진을 유지했다.
- 제주 삼성혈, ID `127744`, 삼성로 22: 사진 있고 `Type1`. 국가유산 사진을 확보했으므로 대체하지 않았다.
- 같은 삼성혈 검색에 음식점 ‘삼성혈해물탕’도 반환됨. 이름 일부가 같아도 주소·분류가 다르므로 연결 후보에서 제외했다.
- 불탑사(제주), ID `317558`, 원당로16길 41: 사진 있고 `Type3`. 사찰 사진을 오층석탑 자체 사진으로 간주하지 않았으며 대체하지 않았다.
- 김정희 종가·동여비고·천여불수반수기앙이 검색은 제주 범위에서 0건이었다. 더 넓은 이름 유사 검색으로 다른 장소 사진을 가져오지 않았다.

이번에 TourAPI 사진을 새로 국가유산에 연결한 것은 없다. 기존 연결 구조와 정상 관광 사진은 유지했다.

## 한수풀 해녀학교

정확한 TourAPI 항목: ID `930345`, 명칭 ‘한수풀 해녀학교’, 주소 ‘제주특별자치도 제주시 한림읍 한림해안로 623-6’.

- 붙여 쓴 ‘한수풀해녀학교’ 검색은 0건. ‘한수풀’ 또는 ‘해녀학교’ 검색으로 정확한 항목 확인.
- 검색 목록: `firstimage`, `firstimage2`, `cpyrhtDivCd` 모두 빈 값.
- `detailCommon2`: HTTP 200, `resultCode=0000`, 같은 콘텐츠 ID·이름·주소 확인. 대표 이미지 두 필드와 이용허락 필드 빈 값.
- `detailImage2`: 현행 지원 매개변수 `contentId=930345&imageYN=Y`로 HTTP 200, `resultCode=0000`, `totalCount=0`.
- 최초 조사 때 예전 매개변수 `subImageYN`을 함께 넣으면 HTTP 200이어도 상위 오류 코드 `10`, `INVALID_REQUEST_PARAMETER_ERROR(subImageYN)`을 반환했다. 해당 매개변수를 제거하여 정상 빈 결과인지 다시 확인했다. 이 조사 요청 오류를 운영 코드에 추가하지 않았다.
- 따라서 현재 조사한 공식 관광 API에는 사용할 사진이 없다. 다른 해녀 시설이나 AI 생성 그림으로 대체하지 않는다.

실제 요청에는 인증키를 서버 환경변수로 전달했고 키는 문서·로그에 기록하지 않았다.

## 이용 조건 및 카드 처리

추가 국가유산 사진은 모두 개별 공식 사진 원문의 공공누리 제1유형 링크와 API의 `A/F` 코드를 대조했다. 카드의 사진명·제공기관·원문·이용 조건 링크는 기존 연결 방식을 유지한다. 해당 사진만 지정번호와 정확한 파일 경로로 연결한다.

공통 카드의 기존 레이아웃과 CSS는 보존하고, 이미지 실패 시 상태만 전환한다. 기본 영역은 🌿 아이콘과 ‘사진 준비 중’ 문구로 표시해 실제 사진으로 오해하지 않도록 했다. 이미지 주소가 바뀌면 새 사진을 다시 시도하며, 실패한 사진으로 무한 재시도하지 않는다.
