# Home·Explore 이야기 목록 통일

## 중단 지점에서 이어서 처리

통합 브랜치 `codex/integration-student-app`의 마지막 커밋 `38a66a5` 뒤, 수정 파일 4개와 신규 파일 2개가 남아 있었다. 기존 파일을 되돌리지 않고 완료된 공통 데이터 연결을 유지했다. 중단 전 자동 테스트 59개와 빌드는 이미 통과했으며, 남은 브라우저 검증·회귀 확인·문서화를 진행했다.

## 공통 데이터와 출처

- 기존 Home의 학생용 7개 본문을 `src/data/studentStories.js`로 그대로 이동했다.
- `src/data/storyCatalog.js`에서 출처·분류·표시 메타데이터와 외부 검증 데이터의 공통 목록을 구성한다.
- Home은 이 공통 목록에서 추천 항목을 최대 7개 선택하며 Explore와 상세 화면은 같은 전체 목록을 사용한다.
- 원본 커밋 `38a66a5`의 Home 배열과 대조해 제목·본문·장면·질문·소개·출처가 모두 보존됨을 확인했다. 별도 지도 메타데이터만 기존의 검증된 `jejuMapPins.json`에서 연결해 중복된 옛 좌표를 없앴다. 지도 JSON 자체는 변경하지 않았다.
- 기존 `MYTH_CONTENT_VERIFICATION.md`의 개별 이야기 근거를 사용했다. 이 문서의 ‘우선 추천 7선’과 기존 Home 7개의 구성은 일부 다르므로 그 추천 표와 완전히 같은 7개라고 주장하지 않는다. 자청비 등은 문서 내 개별 검증 항목을 근거로 포함한다.
- 기초 원문·이미지: 제주특별자치도 「제주신화전설 삽화 정보」와 `mythStories.js`의 보존된 원문 및 이미지. 학생용 문장은 기존 Gemini 풀이이며 원문과 동일한 문장이라고 표현하지 않는다.
- 혼인지의 기존 Home에 있던 역사문화 자료 기반 본문·출처를 공통 목록으로 옮겨 오래된 검증 대기 상태를 정리했다.
- 옛 제목 ‘삼신인의 혼인’과 ‘삼성혈’은 검색 별칭으로 보존한다. ID를 바꾸거나 기존 즐겨찾기를 갱신하지 않았다.
- ZIP 조사 후보 49개와 CSV 59개를 완성된 웹 이야기로 자동 등록하지 않았다. 새 이야기·이미지를 만들거나 기존 콘텐츠를 삭제하지 않았다.

## 표시·탐색 규칙

- 현재 Home 추천 7개 / 전체 7개, Explore 기본 전체 7개 중 7개 표시.
- 모든 개수는 실제 목록 길이에서 계산한다. 추후 전체 목록이 늘면 추천 7개와 전체 N개가 구분된다.
- 지도 장소 6곳은 별도 JSON의 검증된 실제 위치 개수다. 전체 이야기 개수와 혼합하지 않는다.
- 자청비는 이야기 목록·상세 화면에 포함하지만 고정 장소·좌표는 만들지 않는다.
- Home 카드의 기존 선택 동작은 유지해 이야기·지도·날씨 선택을 깨뜨리지 않았다. 각 카드의 ‘상세 이야기 보기’ 링크로 해당 상세 경로에 진입한다.
- Home ‘전체 이야기 보기’는 `/explore`로 연결된다. Explore 카드 클릭은 `/explore/:id`로 이동한다.
- 상세 페이지는 이야기 ID가 바뀌면 장면 위치를 초기화한다. 학생용 본문과 장소 설명도 동일한 공통 데이터에서 읽는다.
- ‘삽화 있는 것만’ 필터를 켜면 현재 로컬 삽화가 연결된 2개만 표시한다. 이 경우 ‘전체 7개 중 2개 표시’로 필터 결과임을 구분한다.
- 같은 ID에 외부 검증 메타데이터를 추가해도 중복 행을 만들지 않으며, 장면이 생략됐다는 이유로 기존 본문을 지우지 않는다.
