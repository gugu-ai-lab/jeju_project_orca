# 신화 삽화·설명 출처와 이용 조건

## 1. 자료 식별
- 자료명: 제주특별자치도_제주신화전설_삽화_정보_20160810
- 제공: 제주특별자치도 (공공데이터포털) https://www.data.go.kr/data/15051457/fileData.do
- 구성: 이미지 42개 + 설명 CSV(`신화전설_삽화_설명.csv`, 59행). 파일별 목록과 대응 관계는 `INVENTORY.md`.

## 2. 데이터셋 이용 조건 (데이터셋 단위)
- 이용허락범위: **공공저작물 자유이용(제0유형)**
- 확인 경로: 사용자가 공식 데이터 페이지에서 직접 확인해 전달함(2026-11-02). 이 작업에서 해당 페이지를 직접 열람해 검증하지는 않았다.
- 웹 검색으로는 이 데이터셋 페이지를 찾지 못했다.

## 3. 파일 단위 확인 결과
- ZIP 안에는 이미지별 저작권·이용조건 파일이나 메타데이터가 **없다**. 이미지별 개별 제한은 ZIP에서 확인되지 않았고, 이용 조건은 위 데이터셋 단위 표시에 따른다.
- 이미지별 촬영자·삽화가 정보는 자료에 없다(미확인).
- 설명 CSV는 이미지와 같은 데이터셋의 파일이며 동일한 이용 조건으로 간주한다.

## 4. 처리 내역
- `assets/original/` 의 파일은 ZIP 원본 바이트 그대로이며 수정하지 않았다.
- 원본 확장자는 일부가 `.png`, 일부가 `.jpg` 이지만 **42개 모두 실제 형식은 JPEG** 이다(파일 헤더로 확인).
- `public/myth/*.jpg` 는 화면용 사본이다. 비율을 유지해 긴 변 1100px, JPEG 품질 80으로 줄였고, 실제 형식(JPEG)과 확장자(`.jpg`)가 일치한다.
- 화면에 사용 중인 삽화: 설문대할망전설, 설문대할망과오백장군전설, 삼성혈, 삼성혈(삼신의3공주).

## 5. 미확인 사항
- 삼성혈(삼신의3공주) 이미지: CSV `삼성혈(삼신인의 3공주)`와 파일명이 한 글자 달라 대응을 확정하지 않았다. 화면에서는 이 이미지에 CSV 설명을 붙이지 않는다.
- 서촌꽃놀이 / 은혜갚으노루 이미지도 CSV 이름과 한 글자씩 달라 미확인이다.
- 각 이야기의 신화·전설·민담 분류, 연결 관광지는 이 자료에 없다. Gemini의 원본 검증 결과를 받은 뒤 반영한다.
