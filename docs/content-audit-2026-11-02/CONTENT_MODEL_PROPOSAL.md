# 확장 설계안 (구현 전 제안)

이번에는 앱 코드·기존 카드·라우트·다른 에이전트의 코드를 변경하지 않았다.

## 데이터 구조
| 단위 | 주요 필드 |
|---|---|
| Story | 영구 ID, 표시 제목, 원문 별칭, 신화/전설/민담/의례 분류, 태그, 요약, 출처, 검토 상태 |
| Scene | 장면 ID, 이야기 ID, 장면 순서, 이미지 ID, CSV 행 번호, 해당 장면의 원문 설명 |
| Asset | 원본 ZIP 내부 경로, SHA-256, 실제 MIME, 크기, 라이선스 근거 |
| PlaceLink | API·콘텐츠 ID, 장소명·주소·좌표, 이야기와의 관계, 관계 근거, 위치 조회 근거, 확인 시각, 방문 가능 상태 |

숫자가 붙은 자청비1·2, 산방덕이1·2는 이야기 2개로 만들지 않고 하나의 이야기 아래 장면을 둔다.
원본 오탈자는 원문 필드에 보존하며 표시명과 명시적 별칭으로 검색한다.
기존 카드 ID·링크·저장 키·컴포넌트 인터페이스는 유지한다. 실제 필드가 다르면 호환 어댑터로 연결한다.
49개 묶음은 편집상 콘텐츠 단위이며 학술적인 고유 이야기 수를 확정한 것이 아니다.

~~~json
{
  "id": "story-jacheongbi",
  "title": "자청비",
  "aliases": ["자청비1", "자청비2"],
  "kind": "myth",
  "scenes": [
    {"csvRow": 44, "assetName": "제주신화전설_자청비1.png", "order": 1},
    {"csvRow": 45, "assetName": "제주신화전설_자청비2.png", "order": 2}
  ],
  "places": [],
  "contentStatus": "editorial_review"
}
~~~

## 지도 활성화 조건
PlaceLink는 아래 조건을 모두 확인한 경우에만 지도에 표시한다.
1. 실제 공공 API에서 관광지 ID·주소·유효한 좌표를 확인.
2. 해당 이야기와 장소의 관계를 CSV 또는 제공기관 자료에서 확인.
3. 장소명 유사성이나 LLM 추정만으로 연결하지 않음.
4. 관계 근거·위치 근거·검증 시각을 각각 기록.
5. 장소 존재 여부와 방문/입장 가능 여부는 분리. 확인 전 방문 가능하다고 표시하지 않음.
6. 장소가 없는 이야기에도 삽화·이야기 탐색을 제공.

이번 작업에서 신규 지도 연결은 0건이다.
- 삼성혈: CSV 22·23행과 이전 TourAPI 실조회 ID 127744, 주소·좌표 확인 기록이 있다.
- 설문대할망→돌문화공원: 기존 카드 유지. 이 ZIP 설명만으로 공원과의 관계를 확정하지 않는다.
- 혼인지: 이 ZIP에는 혼인지 이름의 독립 이미지나 CSV 행이 없다. 기존 카드의 별도 출처·자산을 유지하며 삼성혈 삽화를 혼인지 전용으로 자동 전용하지 않는다.
- 산방덕이→산방산/산방굴사, 수월봉과 녹고물→수월봉, 날아온 섬 비양도→비양도, 김녕사굴→해당 동굴은 확인할 후보다. 이번에 실제 관광 API 조회를 추가로 수행하거나 지도 활성화하지 않았다.
- 자청비·영등할망·삼승할망·소별왕은 장소 미확정 상태로도 탐색할 수 있다.

## 가져오기와 품질
- 확장자는 PNG 41개/JPG 1개지만 실제 형식은 모두 JPEG. 원본은 그대로 두고 앱용 사본을 만들 때 실제 MIME과 .jpg 또는 변환 형식을 맞춘다.
- CSV는 CP949다. 원본은 그대로 두고 파생 레지스트리만 UTF-8로 작성한다.
- 설명에는 줄거리·장면·발췌·미완결 단편이 섞여 있으므로 59행을 모두 완결된 이야기로 공개하지 않는다.
- 고종달: 그림은 바다·배 장면, CSV 5행은 풍수사 파견 설명이므로 장면 설명 추가 검토.
- 서천꽃놀이: 파일명 표기 수정 관계는 명확하나 그림과 놀이굿 설명의 장면 수준 대응은 추가 검토.
- 각 항목의 역사·지질 서술은 관광 사실이나 학술적 확정 사실로 자동 전환하지 않는다.
- 모든 항목의 원문 제목, 출처, CSV 행 번호를 보존한다.

## 작은 단계의 우선순위
1. 기존 설문대할망·삼성혈·혼인지 카드의 동작과 식별자를 유지.
2. 자청비 1개 콘텐츠(삽화 2장)만 추가해 다중 장면 구조 검증. 지도 연결 없음.
3. 수월봉과 녹고물 1개 추가 후 장소 관계·API 좌표를 확인해 지도 연결 1건 검증.
4. 영등할망·삼승할망·소별왕, 산방덕이·비양도·김녕사굴을 하나씩 추가.
5. 설명이 짧은 단편과 삽화 없는 14묶음은 후순위. 이번에 모두 구현하지 않음.
